# Marketing Funnel & A/B Test Analysis

## Business Question
At which stage do visitors drop off the most, and do any segments behave differently?

## Data Source
Dataset: "Synthetic Web Analytics Funnel Events" by GenerateRealData
(https://generaterealdata.com), licensed under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).
Kaggle: https://www.kaggle.com/datasets/generaterealdata/synthetic-web-analytics-funnel-events

Note: this dataset is synthetic. The analysis demonstrates methodology
and does not describe a real business. The original data was cleaned,
joined across tables, and aggregated into funnel metrics.

## Key Findings
   - Overall conversion: 9.06% (84,000 sessions)
   - Largest drop-off: Viewed Product → Added to Cart (59.9%)
